# UI Design Prompt — Nirmana Printing (for Google Stitch)

Use this prompt on its own, per screen, when generating designs in Stitch.
Pair it with a one-line description of the specific screen (e.g. "Orders
list view" or "Add Stock form").

---

Design a **calm, visually pleasing admin dashboard UI** for a printing
shop's internal stock and order management system. This is a tool staff
will use all day, so the priority is a soft, welcoming, low-stress
aesthetic — not a dense, heavy, corporate ERP look.

**Layout**
- Left sidebar navigation + simple top bar
- Card-based dashboard sections with generous whitespace
- Clean data tables for lists (orders, stock, payments)
- Simple, well-spaced forms, broken into clear sections rather than one
  long wall of fields

**Typography**
- A soft, modern, rounded sans-serif font — Inter, Poppins, Manrope, or
  Nunito
- Light-to-medium font weights throughout; avoid bold, heavy, or
  slab-style fonts
- No large blocks of bold or all-caps text
- Comfortable line height and letter spacing — text should feel easy to
  read, not dense or shouty

**Color palette**
- Soft, muted, calming tones — warm off-white or light neutral gray
  background, never harsh pure white or pure black
- One gentle accent color for primary actions and links — a soft blue,
  teal, or sage green
- Status badges (order status, payment status, stock level) in
  desaturated, muted versions of amber/red/green — informative, never
  alarming or neon
- Overall palette should feel closer to a wellness or productivity app
  than a traditional business system

**Shape & depth**
- Rounded corners on cards, buttons, inputs, and badges
- Soft, subtle shadows instead of hard borders
- Airy spacing — generous padding around every element, even in
  data-dense tables

**Icons**
- Simple, consistent line-icon style (Lucide/Feather-style), not heavy
  filled icons

**Overall vibe**
- Calm, friendly, uncluttered — think Notion, Linear, or a light Tabler
  theme
- The system should feel pleasant and easy on the eyes for someone
  looking at it for hours, while still clearly organizing dense
  operational data (orders, stock, payments)

Keep this exact style — fonts, palette, spacing, corner radius, icon
style — consistent across every screen so the whole app feels like one
cohesive product.
